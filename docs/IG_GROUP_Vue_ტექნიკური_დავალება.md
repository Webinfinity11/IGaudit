## 8. დიზაინის მოთხოვნები

- **სტილი:** მკაცრი, საქმიანი, „ჰაეროვანი“ — ბევრი თავისუფალი სივრცე, ზედმეტი ანიმაციების გარეშე (მხოლოდ მსუბუქი fade/hover ეფექტები).

  ```css
  :root {
    --color-primary: #0F2A4A;   /* მუქი ლურჯი */
    --color-surface: #FFFFFF;   /* თეთრი */
    --color-accent:  #C9A227;   /* აქცენტი (მაგ. ოქროსფერი) — დასაზუსტებელი */
    --color-text:    #1A1F2B;
    --color-muted:   #5B6475;
    --color-bg-alt:  #F4F6F9;
    --color-border:  #E3E7EE;
  }
  ```
- **შრიფტი:** ქართული ანბანის სრული მხარდაჭერით — **Noto Sans Georgian** (ან BPG ოჯახი); ლოკალურად ჩატვირთული (`woff2`, `font-display: swap`), საჭირო წონები მხოლოდ (400, 500, 700).
- **ფოტოები:** ლიცენზირებული სტოკი ან გუნდის პროფესიული ფოტოები; WebP/AVIF ფორმატი, სხვადასხვა ზომა (`srcset`).
- **ხატულები:** ერთიანი სტილი (Lucide, ერთნაირი stroke).
- **Breakpoints:** mobile < 640, tablet 640–1023, desktop ≥ 1024, max კონტეინერი ~1200px.
- **მაკეტი:** აწყობის დაწყებამდე დეველოპერი წარადგენს დიზაინის მაკეტს (მთავარი გვერდი + ერთი შიდა გვერდი) დასამტკიცებლად.

## 10. ტექნიკური მოთხოვნები

### წარმადობა
- ჩატვირთვა მობილურზე **≤ 3 წამი**; Lighthouse (mobile): Performance ≥ 90, Accessibility ≥ 95, Best Practices ≥ 95, SEO ≥ 95.

### SEO
- ყოველ გვერდს — უნიკალური `<title>` და `<meta name="description">` (`useSeo` composable).
- Open Graph / Twitter მეტა, `og-image`.
- `canonical`, `hreflang` (ka / en).
- `sitemap.xml` (ბილდისას გენერირდება) და `robots.txt`.
- სტრუქტურირებული მონაცემები (JSON-LD): `Organization` / `AccountingService` — სახელი, მისამართი, ტელეფონი.

- რეგისტრაცია Google Search Console-ში.

### ხელმისაწვდომობა (a11y)
- WCAG 2.1 AA კონტრასტი; კლავიატურით სრული ნავიგაცია; ხილული focus.

- `.env`-ის საიდუმლოები არ ხვდება რეპოზიტორიაში (`.env.example` თანდართული).
